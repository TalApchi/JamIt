# JamIt

JamIt is an interactive mobile music app that turns the screen into a playable virtual instrument.

## Features

- Multiple playable instruments
- Multi-touch controls
- Major and natural minor scale selection
- Sustained notes
- Smooth transitions between sounds
- Interactive visual interface

## Built With

- React Native
- Expo
- TypeScript
- Expo Audio

## About

JamIt was created as a personal project exploring mobile development, interactive audio, multi-touch input and digital musical instruments.
